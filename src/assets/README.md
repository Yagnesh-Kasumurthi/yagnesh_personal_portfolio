# Assets Architecture

This folder contains static and media assets for Yagnesh Kasumurthi's portfolio.

## Directory Structure

- `images/profile/`
  - Place professional photograph / headshot of Yagnesh here (e.g. `yagnesh-photo.jpg`).
  - Hero and About sections link to this location.

- `images/projects/`
  - High-resolution architecture diagrams, block diagrams, and interface screenshots for projects:
    - AI-based Smart Waste Detection
    - LiFi Text Communication
    - Assistive Communication Device (future)

- `images/certifications/`
  - Certificate scans, badges, or preview images:
    - IBM AI certificate
    - Udemy VLSI Design certificate
    - GeeksforGeeks Python certificate

- `documents/`
  - Official resume PDF (e.g. `Yagnesh_Kasumurthi_Resume.pdf`).

- `icons/`
  - Custom SVG icons for specialized hardware, EDA tools, and platforms.
